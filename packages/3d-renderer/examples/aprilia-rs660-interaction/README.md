# Aprilia RS 660 外观部件交互演示

## 这次做了什么

- 保留原始 GLB，不覆盖、不改写源文件。
- 按完整对象或完整连续网格岛重组，未用平面硬切模型。
- 整车整理为 16 个分组：1 个机械基础层 + 15 个可交互外观部件组。
- 提供 Blender 可编辑文件、拆分后的 GLB、部件清单和本地网页演示。
- 网页支持旋转、缩放、爆炸展开、点击选件、单独查看、隐藏/显示、改色、贴膜预览、导入替换 GLB 和一键复原。

## 如何打开网页

macOS：双击 `启动演示.command`，浏览器会自动打开本地演示。

也可在本目录运行：

```bash
python3 launch.py
```

出现地址后，用浏览器打开显示的 `http://127.0.0.1:端口/`。不要直接双击 `index.html`，浏览器通常会阻止本地模型加载。

## 交付文件

- `Aprilia-RS660-editable.blend`：分组后的 Blender 可编辑工程。
- `Aprilia-RS660-split.glb`：网页使用的拆分模型。
- `index.html` / `app.js` / `style.css`：交互网页。
- `manifest.json`：部件编号、对象组成、面数及几何校验。
- `assignment-audit.json`：源对象和连续网格岛的分配审计。
- `browser-check.json`：浏览器功能验收记录。
- `assembled.png` / `exploded.png`：Blender 静态检查图。
- `web-assembled.png` / `web-exploded.png`：网页端验收截图。

## 部件分组

机械基础层、左右后视镜、风挡及边框紧固件、车头外壳与灯组、前挡泥板、油箱外壳、主坐垫、后座与尾壳总成、左右整流罩、底部导流罩、前后轮总成、排气尾段、牌照架与后挡泥板。

## 验收结论

- 拆分前后均为 232,248 个面。
- 世界坐标几何、UV 与材质签名一致。
- 网页加载 16 个分组，无启动错误。
- 爆炸展开时机械基础层保持原位。
- 单独查看、隐藏/显示、改色、贴膜与恢复、错误替换件保护、一键复原均通过。

## 使用边界

- 车型名称按文件名和模型外观标注为 `Aprilia RS 660 2021`，没有核验原始素材页面及授权条款。
- 这是一套外观交互演示分组，不是维修拆装教程，也不代表真实零件适配关系。
- 原模型把许多零件按材质合并；为避免锯齿和碎片，本次只拆出视觉上可靠的关键总成，车架、发动机、前叉等机械主体保留在基础层。
- 贴膜功能是网页平面投影预览，曲面边缘可能拉伸，不会写回原始纹理。
- 导入替换件后需要人工微调比例、位置和旋转；无效 GLB 不会删除或覆盖原件。
- 当前成果只保存在本机，没有推送 GitHub。
