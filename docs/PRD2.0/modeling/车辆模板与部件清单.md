## 稳定编号规则

- 整车模板编号：`KAW-DEMO-TPL-001`。
- 部件槽位：`KAW-DEMO-SLOT-001` 至 `KAW-DEMO-SLOT-015`。这些是模板槽位，不是商品 `partId`，也不是公共 API 枚举。
- 贴膜区域：`KAW-DEMO-WRP-001` 起。区域只有在 mesh、材质槽、UV、遮罩和恢复方式齐全后才标“可交接”。
- 准确车型确认后保留旧编号与新正式编号的映射，不静默改号，避免前端和配件资产失联。
