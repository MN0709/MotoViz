## 独立替换检查（每个准备支持的部件填写）

- [ ] 能定位唯一或明确的一组原车对象，不与不可替换车身焊死为一个网格。
- [ ] 隐藏该部件不误删无关车身；连接处和被遮挡区域有合理处理。
- [ ] 定义安装位置、方向、尺度及需要的多点连接/路径；不能所有部件都套单挂载点。
- [ ] 明确整套/局部替换及占用关系，避免原车和新配件重叠。
- [ ] 缺少新模型时保留原装；可恢复原装并保持其他选择。
- [ ] 记录模板版本与验证截图/操作证据，资产改版后能追查影响。
