# 建模资料需求单模板

由建模组以视觉展示够用为原则提出需求，RAG 组按单提供已有资料及缺项。不得默认把全部精确尺寸和细节图设为必需。复制下方记录到本文件或独立需求文件，并在交接台账链接；示例字段不代表已要求某个像素值或误差。

## 需求身份

| 字段 | 填写值 |
| --- | --- |
| requestId / 版本 | 待填 |
| 车型与模板版本 | 450SR 2025 普通版 / 待填 |
| 部件编号、名称、拆分范围 | 待部件清单确定 |
| 拟建具体品牌/型号/规格 | 待核实；无具体产品时不能写“天蝎排气”即视为完成 |
| 提出人/日期 | 待填写，沿用原职责 |
| 制作方法与资料用途 | 待建模组提出 |

## 资料规格（建模组填写）

| 资料项 | 具体要求/单位/规格 | 必需或可选 | 影响的建模环节 | 可接受的替代资料 | RAG 回应/缺项 |
| --- | --- | --- | --- | --- | --- |
| 外形与比例参考 | 可用尺寸、参考图比例或建模组视觉估算；分别标注依据 | 比例基准必需，精确尺寸选填 | 大小协调、轮廓可辨 | 同车参照物/多图对比，记录估算 | 待填 |
| 场景替换基准 | 待填安装位置、方向与隐藏边界；精确孔距等按需补充 | 可替换基准必需，工程细节选填 | 与整车视觉衔接 | 经场景验证的调整值 | 待填 |
| 图片角度 | 待填需要哪些视角、细节、遮挡要求 | 待定 | 外形复原 | 待填 | 待补 |

## 建模组验收回复

资料包 ID/版本：待填。结论：待验收 / 可建模 / 需补充 / 暂不可用。缺项、冲突、是否允许先做局部以及不能验收的部分：待填。验收人、日期和证据：待填。

允许为视觉模型估算尺度或优化几何，必须单列为“视觉估算/场景调整值”，由建模组负责，不能写为官网尺寸或实测事实。引用其他对象作辅助参考需明确其用途，不能冒充目标产品资料。缺少精细资料可先做可优化初模，只把确实阻止比例/替换的缺项列为阻塞。
