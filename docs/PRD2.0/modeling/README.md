# 建模组工作区

3D组当前按会议后分工执行：@siguadht模板、@kevin-long26配件、@20050202ys-sketch图生图与贴图、@Freya-Qian页面交互，见[分工表](../shared/团队分工.md)。先填写模板和资料要求，再取资料建模，不先随意生成一个不可拆整车。

| 顺序 | 文档 | 建模组应填写的内容 |
| --- | --- | --- |
| 1 | [车辆模板与部件清单](车辆模板与部件清单.md) | 完整候选部位分组、编号、拆分边界、原车节点、替换规范及预留状态 |
| 2 | [建模资料需求单](建模资料需求单.md) | 每类部件实际需要的尺寸、图像、角度、安装结构与格式 |
| 3 | [模型资产登记](模型资产登记.md) | 资料验收、模型/产品对应关系、尺度、挂载和验证 |
| 4 | [贴膜模板与方案登记](贴膜模板与方案登记.md) | UV、材质区域、遮罩、纹理输入要求及旋转预览验证 |

各成员在记录中填写本人账号、更新日期、证据和阻塞，不重复建立自己的独立编号体系。当前未填的技术参数不由其他组猜测。

可复用的旧资产见[迁移清单](../migration/迁移清单.md)，通用模型不是 450SR 真车模型。刹车管线等只是用户举例，不因此自动加入已冻结交付列表。

## 建模标准

验收重点为比例一致、可替换、可继续优化。允许简化非关键结构、先生成初模后优化，不把官网精确参数齐全或实物逐处一致设成统一前置条件。建模估算写在模型记录，RAG原始参数保留来源和未知状态。
