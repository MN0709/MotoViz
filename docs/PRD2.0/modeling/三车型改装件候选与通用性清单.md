## 先说清楚“通用”是什么意思

本表把“通用”拆成两件事：

1. **接口通用**：三台车都可使用同一个 `slotKey` 和同一套替换/恢复流程。
2. **实体通用**：同一件真实配件不改孔位、不加转接件，就能直接装到三台车上。

结论：**大部分改装件只能做到接口通用，实体件不能直接通用。** 真正接近通用的只有改色膜、拉花膜、轮毂贴等原材料；它们仍要按不同车壳和轮毂重新裁切。后视镜、护弓等只有在螺纹、孔距和转接座一致时才能复用，不能默认通用。

当前川崎模型的准确型号和市场版本尚未核实。下表中的川崎品牌只能作为找资料候选；在车型身份确认前，不得写成“已适配 ZX-25R 商品”。

## 给 #38 和 #40 的交付要求

每个最终采用的“车型 × 改装件 × 品牌款式”必须有唯一记录，至少包含：

- 车型、年款、市场版本和来源链接；川崎身份未确认时保持“待核”。
- 品牌、商品名称、商品编号、适配年款；没有官方适配证据时写“视觉参考”，不能写“适配”。
- 前、后、左、右、顶、底六视图；细节图包含安装面、孔位、支架和连接管。
- 长宽高、孔距、内外径、连接角度等能找到的参数；找不到时写未知，不猜数字。
- 图片和模型使用许可；不直接搬运带版权水印的商品图进入公开仓库。
- 对应 `vehicleId + templateVersion + slotKey`、需隐藏的原车节点、默认位置/旋转/比例和冲突部件。
- 交互验证证据：加载、隐藏原件、显示新件、无明显悬浮穿模、恢复原件。

## 建模顺序建议

1. 先为三车分别做 **风挡 + 排气尾段**，因为当前槽位已经存在，外观差异明显，最适合验证换件。
2. 再做 **后视镜 + 短尾牌照架**；后视镜主体可尝试复用，但必须保留三套转接变换。
3. 再做 **整流罩改色/贴膜**，复用渲染流程，三车分别保存 UV/遮罩。
4. 水箱网、发动机盖、防摔球、护弓等没有现成槽位，等首批切片验收后再新增。
5. 轮组、脚踏、定风翼暂不进入首版，避免十天 MVP 继续扩张。
