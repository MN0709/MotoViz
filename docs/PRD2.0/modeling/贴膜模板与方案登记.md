## 首个模板包 `KAW-DEMO-WRP-001` 的通过条件

1. 写明模板版本、mesh 节点和材质名称/索引。
2. 导出与模型一致的 UV 布局 PNG，标明 UV 通道、是否重叠或镜像。
3. 提供同尺寸黑白遮罩，白色为可绘制区、黑色为保护区；灰色只用于软边并说明规则。
4. 规定纹理尺寸、PNG 格式、sRGB、透明通道和安全留边。
5. 标明上下左右方向、接缝、不可覆盖区域。
6. 提供编号棋盘格应用后的左侧、前 45°、后 45°截图。
7. 提供原材质备份和恢复步骤；失败时必须保留上一有效纹理或原车材质。

浏览器中通过平面投射显示本地图片，只能证明交互链路能换纹理，不能代替以上 UV/遮罩模板包。
