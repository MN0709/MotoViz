## 候选CSV解释

独立解析确认：357 行数据、10 个字段、每款车型119行；列名`摩托品牌`实际承载车型和年款。源文件第一列含UTF-8 BOM，保留原样。组长的阶段验收指出大量来源仍是站点/店铺首页，完整字段不等于完整证据。

复制数据不等于获得其中外部图片的使用许可；RAG 组需要按新资料需求记录来源、访问情况和允许用途。移入2.0不会自动升级为A类或可建模。
