1. 模板负责人先给部件/区域草案、编号和够用的资料规格。三位资料成员可同时整理已有参考，不必等待所有编号冻结。

仅首发450SR2025普通版；不自行增加具体配件数量、截止日期或付费采购承诺。请各人先回执预计首个可核验交付时间与依赖。旧RAG开发当前暂缓，资产与代码保留。
