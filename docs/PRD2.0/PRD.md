## 1. 问题与目标

当前主要问题是建模规划与数据交接脱节：整车如果没有预先拆出可替换部件，后续即使取得配件模型也难以正确替换；RAG 资料中的产品、图片、尺寸和 3D 资产缺少一致标识，建模组无法直接获得所需资料。

2.0 以车辆模板为起点，建立“部件清单及编号 → 建模资料规格 → RAG 资料包 → 建模 → 替换展示”的闭环。官网与现有接口保留复用，不把页面重做或接口重构作为当前工作的起点；这并不代表所有旧功能已经完成或端到端验收通过。

面向用户：改装店工作人员及看方案的顾客。用户价值是围绕明确车型看见配件替换或贴膜拉花效果，能旋转检查、选择方案并输出效果图。

## 核心质量标准：改装可视化

本版以 **比例一致、部件可替换、3D 模型可持续优化** 为核心验收标准。不要求模型与官网图片或实物逐处一致，不以工业级尺寸精度、精细安装结构或每个表面细节复刻作为首版门槛。

- **比例一致**：整车与配件采用一致的场景尺度，配件相对车身及相邻部件大小协调；结合可用参考图或尺寸校准，避免明显大小失衡、悬空或穿模。不是要求所有配件同尺寸。
- **可替换**：部件独立拆分，替换、隐藏、恢复不破坏其他部件，并可旋转查看。
- **可优化**：允许先生成可用初模，再调整外形、尺度、位置、材质/纹理及网格复杂度。保留可编辑源文件或可继续编辑的资产、导出文件与版本记录；GLB 本身不自动证明模型容易修改。
- **资料够用即可启动**：有能识别对象和轮廓的参考资料、可采用的比例基准，即可由建模组判断是否开始。缺少官网精确尺寸、孔距或细节图，不一律阻断视觉模型制作；由建模组按视觉需要标明必需项和后补项。
- **事实与视觉参数分开**：RAG 提供有出处的原始信息；建模组可填写“视觉估算/场景调整值”，不能把它回写成官网参数或实物测量值。未核实实际适配不阻止清楚标注的视觉方案试装，但不能对外宣称真实可安装。

具体产品的参考近似模型可以用于视觉展示，标注“改装效果示意”；通用预设继续标“预设效果示意”。二者均与真实商品事实、实际安装适配分别记录。贴膜链路同样以区域、比例、可旋转效果和可修改纹理为重点，不要求实物印刷级复刻。

## 2. 本版范围

### 2.1 已确认

- 首版聚焦中国大陆 **2025 款春风 450SR 普通版**。此前讨论的 250SR 不再是本版首发车型；旧三车型数据仍保留。
- 两个最小业务：配件视觉展示；贴膜拉花视觉展示。两者均以可旋转的 3D 车辆为载体，不以单张二维生成图替代 3D 交付。
- 建模组先梳理可改装部件、分组、编号和拆分规范，整车建模时能够独立隐藏、移除、恢复和替换相应部件。
- 建模组提出各类资料的具体要求，例如可用比例参考、必要视角、分辨率及格式；实物精确尺寸和安装细节按视觉需要选填；RAG 组整理并提供对应资料，建模组验收后建模。
- 可用的 1.0 成果保留迁入；原成员、组别、职责与 Ethan 的任务不变。
- 本次只交 PRD、分组文档及成果归档，不执行新排期、派单、合并或功能开发。

### 2.2 首版需继续定义的范围

模板应考虑哪些可替换部位，由建模组提出清单；**完整可改装清单尚未提交，不在本文冒充已经核实**。排气、链条、后视镜和刹车管线都是解释需求的例子，不自动变成首版全部必做项。

首批具体配件类别、产品型号和数量，待部件清单和资料可用性明确后确定。此前“三个排气品牌”的例子不等于三款已经选定、适配已证实的商品；“天蝎”只是其中一个品牌示例，不限定品牌范围。

### 2.3 保留但非本版核心路径

旧图片转配件 3D 的入口及同类型预设降级规则保留为已有需求背景；它不再是本版两条核心链路的前置依赖。自动生成不能满足部件拆分、尺寸与形状要求时，由建模组提出可行制作方法，生成初模可以继续优化后交付，不要求首次生成即达到最终效果。该入口如何与 2.0 页面并存、生产服务如何启用，另行对齐。

故障诊断、维修手册扩展、前后对比分屏、更多车型和知识库管理不作为本版两个业务的首要验收目标。历史分支与任务继续留存，不因此删除成员工作。

## 3. 业务一：配件替换视觉展示

### 3.1 用户流程

选择 450SR 2025 普通版 → 浏览已支持的可替换部位 → 查看该部位的具体配件及资料 → 选择商品 → 隐藏相应原车对象并加载替换模型 → 旋转、缩放查看 → 恢复原装或切换商品 → 保存方案并导出效果图。

### 3.2 生产流程

1. 建模组交付车辆模板的部件清单与编号：记录拆分边界、原车对象、安装基准、关联部件及状态。
2. 对本轮拟制作的部件，建模组填写资料需求单；数值要求由建模组给出，其他组不猜测。
3. RAG 组优先查现有候选库，定位具体产品，提供可用参数/参考图片、比例依据和来源，记录实际适配是否已核实；不要求资料达到工业复刻完整度。检索摘要不能代替建模原始资料。
4. 建模组对资料包判定可建模、需补充或暂不可用。退回时指明缺哪项及其影响。
5. 模型制作完成后，登记具体商品 ID、部件编号、车辆模板版本、文件版本、尺寸坐标及资料包版本。
6. 在该车型模板上验证独立替换、原车部件隐藏、比例、位置、关联件和恢复原装，再交前端展示。

### 3.3 核心规则

- 一个品牌可能有多款产品。资料、图片和模型必须对应具体产品，不能靠品牌名或文本相似度绑定。
- 同一部位替换需处理占用关系；全段与尾段排气等可能影响不同原车对象，具体规则由建模组确定。
- 无可用模型或未通过场景比例/替换检查：保留原装，展示信息并标“暂不支持 3D”，禁用该项替换。参考近似模型通过视觉检查后可用于明确标注的效果展示；实际适配状态单独呈现。
- 旧通用预设仅用于明确标注的示意流程；不得将其包装为所选真实商品的装车结果。
- 模板几何验证、商品适配证据分别记录；画面无穿模并不能证明实物可安装。
- 保存内容至少可追溯到车型模板、所选商品、模型版本与视觉来源状态；具体持久化和文件格式待组内提出。

## 4. 业务二：贴膜拉花视觉展示

### 4.1 用户流程

选择同一车辆模板 → 选择可贴区域 → 输入文字或参考图 → 文生图/图生图生成设计方案 → 转换或整理成符合模板的纹理 → 应用到对应车身材质区域 → 旋转查看 → 修改或重新生成 → 保存方案并导出效果图。

### 4.2 模板依赖

建模组必须交付可贴部件、区域编号、UV 布局、材质槽和遮罩模板，并说明纹理规格、方向、留白、接缝和不可覆盖区域。可替换几何与可贴膜区域是两种关系，不能用一个笼统“模型 ID”代替。

文生图/图生图的普通输出不保证满足 UV。需要实际验证从图案到纹理再到 3D 的处理流程；是否需要人工整理、投射或专门生成方式由相关现有负责人提出，不预设供应商或新技术栈。

### 4.3 核心规则

- 仅修改目标区域纹理/材质，不意外替换车型或改变零件几何。
- 多角度查看使用同一辆车和同一套纹理，不用互不一致的视角图片冒充 3D。
- 失败时保留上一个可用方案或原车材质，明确可重试；无模板或 UV 不合格时不能宣称 3D 贴膜成功。
- 输入原图、生成图、实际应用贴图分开保存并记录版本，便于核查与再次调整。
- 效果图用于视觉沟通；可施工展开图、印刷尺寸及生产文件不在本轮已确认交付中。

## 5. 共同数据基础与分组填写

使用一条可追溯关系：**车型/模板版本 → 可替换部件编号 → 具体商品 → 建模资料包 → 3D 资产/绑定验证**。贴膜使用：**车型/模板版本 → 可贴区域/UV 版本 → 设计方案 → 实际纹理资产**。

编号规则及字段见[跨组交接文档](shared/数据关联与交接.md)，属于文档协作草案，不能直接新增公共 API 字段。建模组先填[部件与区域清单](modeling/车辆模板与部件清单.md)，再填[资料需求](modeling/建模资料需求单.md)；RAG 组在[产品资料包](rag/产品资料包模板.md)回应，双方在[交接台账](shared/交接台账.md)记录进度。

RAG 当前已有关键词检索实现分支，不宣称已实现向量数据库。对精确 ID 的资料包查找应能直接定位记录；语义/关键词检索用于发现候选，不能替代车型适配核验。是否增加向量检索依据后续评估，不是本阶段前置条件。

## 7. 验收要求

以下是 PRD 2.0 拟采用的功能验收条件；尚未执行，不代表通过。具体模型预算、纹理尺寸、视觉问题判定、目标设备和耗时值由原负责人填报并与产品对齐，不虚构统一技术数值。

| 编号 | 验收场景 | 通过条件 |
| --- | --- | --- |
| V01 | 检查车辆模板清单 | 编号唯一、原车对象能对应；预留/已支持/未支持分开；拆分边界明确 |
| V02 | 逐项替换已支持部件 | 只隐藏定义的原车对象，无双重叠加；不损坏无关车身；可恢复原装 |
| V03 | 核查产品资料与模型 | 参考对象、车型版本和资料包对应；事实参数与视觉估算分开；缺细节不自动失败 |
| V04 | 模型缺失或无法完成视觉替换 | 保留原车；明确不支持；不能返回其他型号或通用模型冒充 |
| V05 | 已支持配件旋转查看 | 各角度比例、位置合理，明显穿模与遗漏按约定处理；结果可保存追溯 |
| V06 | 应用贴膜并旋转 | 同一方案连续显示在约定区域，不误贴轮胎/灯具等非目标区；检查接缝和拉伸 |
| V07 | 生成/纹理加载失败 | 保留上一可用状态或原装，错误明确、可以恢复或重试 |
| V08 | 导出效果图 | 反映当前车型、商品/设计方案；示意或生成标识保留，不伪装真实安装证据 |
| V09 | 取用 RAG 建模资料 | 按产品 ID 能找到完整资料记录及可用原文件/链接，不仅有文字回答 |
| V10 | 历史成果复用 | 候选不自动转正式、隐藏边箱不重新暴露、参考近似与通用预设标识清楚 |
| V11 | 生成初模后继续优化 | 能调整比例、外形、位置与材质/纹理，保留可继续编辑的资产和修改版本，重新导出后能替换展示 |

历史 30fps、5 秒加载、生成 60 秒等指标留在原任务中供评估；新完整车辆与纹理资源尚未确定，不能声称已有测试证明满足。新指标统一在[待定项](shared/决策与待定项.md)填写后再更新契约或任务。
