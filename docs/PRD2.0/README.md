版本：2.0 初稿 · 2026-09-16。阶段：已按会议后新分工下达任务，先交规格/资料，再推进依赖就绪的小样与联调。

首发车型：**中国大陆 2025 款春风 CFMOTO 450SR 普通版**，不含 450SR-S 或天蝎排气版。两个业务：**配件替换的可旋转 3D 展示；贴膜拉花的可旋转 3D 展示**。

先读 [1.0→2.0 差异与 Codex 交接](shared/PRD版本差异与Codex交接.md)，再读 [PRD 2.0](reports/requirements/PRD.md)，再按[会议后最新任务](shared/任务下达清单.md)填写对应目录。所有空白、待核实项都是真实缺口，不是已完成数据。

## 文档与工程分区

调研报告、需求报告、测试与验收文档统一放在 [reports/](reports/README.md)，按research、requirements、testing分类。各组填写模板继续集中在本PRD2.0目录；运行时代码仍在仓库apps、packages、scripts，不迁移工程路径。

## 填写与维护约定

1. 建模组先提出部件编号、拆分边界和所需资料规格；建模资料组按对应编号提供原始参考资料包；建模组验收资料并制作模型，结果关联回原产品。
2. 各组在自己目录填写事实、证据、负责人、日期、状态和缺项。不要复制出多份相互独立的主清单，跨组用编号和文件链接引用。
3. `待填`、`待核实`、`示例`不得变成正式 API 输入或用户可用数据。模板中的逻辑字段不是已冻结的新接口。
4. 旧成果以副本迁入 `migration/v1/`，保留提交 SHA、原路径与校验值。归档区只读；新增核实结果写入小组文档，不覆盖旧证据。
5. 本期实际启用部件与模板预留部位分开。不要把完整拆分清单等同于首版全部建模承诺。
6. 当前人员任务已按会议决定调整，RAG开发暂缓，旧成果保留；详细执行卡见shared/任务下达清单.md。本次未更改公开API或运行时代码，也未合并功能PR。

## 最新质量口径

改装可视化优先：比例一致、可独立替换、模型可继续优化即可；不要求官网/实物一比一复刻。允许使用明确记录的视觉估算值，精确安装尺寸和完整实物细节不是统一前置条件。详见 [PRD 核心质量标准](reports/requirements/PRD.md)。
