**RAG功能当前暂不用、开发暂缓。** 三位成员转为建模所需数据准备，旧路径`rag/`保留以维护已有链接，不代表继续做检索系统。

资料组按建模组需求提供够用原始参考；来源事实、未知值与视觉估算分别记录，不要求官网/实物一比一复刻。缺精确尺寸可交建模侧判断是否可用，不能用臆造值填满。

旧[357条候选CSV](../migration/v1/rag/候选配件-357.csv)和[450SR119条索引](450SR-候选索引.md)继续保留，配件优先复用，不重采全库。旧三车型数量及截止不再支配本轮数据工作。

[产品资料包模板](产品资料包模板.md)可继续使用；需要匹配具体产品时使用稳定对应关系。先按可用资料记录，部件/区域编号确定后补映射。所有交接写[共享台账](../shared/交接台账.md)。[旧检索说明](检索与资料取用.md)仅作为暂停方案保留。
