## `KAW-DEMO-SLOT-003`：风挡候选 W01

- **对象**：Yoshimura `Wind Armor`，零件号 `522-238-1000`。[厂商产品页](https://www.yoshimura-jp.com/product/n-120649?lang=en)列出 Ninja ZX-25R 2021/2022/2023/2024，以及另一个车型族 ZX-4R SE/RR。此处只记录前者作为**待匹配候选**，不能据此确认现有模型或中国市场实车适配。
- **事实参数**：厂商写明石墨黑聚碳酸酯、厚 2 mm；相对于厂商所称的原厂风挡，长度多 20 mm、顶部高 70 mm。这是**差值**，不是风挡绝对长宽高，更不是现有 3D 模型的比例尺。[安装说明（厂商 PDF，1 页）](https://www.yoshimura-jp.com/wp/wp-content/uploads/2023/06/522-238-1000-211118-%E3%82%A6%E3%82%A4%E3%83%B3%E3%83%89%E3%82%A2%E3%83%BC%E3%83%9E%E3%83%BCNinja-ZX-25R20-.pdf)写明拆除原车风挡并复用原车螺栓、胶螺母、尼龙垫片和罩件；只针对其列出的车款，不证明本项目模型孔位。
- **外观比较**：下表中 01/03 是**原厂风挡**的装车比较图，不是该商品；02/04 是 Yoshimura 风挡。厂商网页在四张图下明确按列标注 OEM / Yoshimura；两个观察角度各一组，不算四张独立商品视角。
