## 图生图输入要求回执

根据 @20050202ys-sketch 在 [#41 的输入适用性回执](https://github.com/MN0709/MotoViz/issues/41#issuecomment-5751555660)，后续每份候选原图按以下工作口径登记：

- 左、右主整流罩各需近正侧主视角和互补斜视；油箱外罩需俯视及左右斜视；左、右尾壳各需后侧局部近景和后上方斜视。
- 建议原图长边至少 1024 px，目标区域最长方向至少 512 px；优先 JPEG/PNG、sRGB，并保留原文件。该数值不是最终 UV 纹理尺寸。
- 每个文件分别记录权利人/提供方、原文件或链接、目标车型版本依据，以及是否允许项目内部参考、上传指定图像编辑服务、团队共享和演示发布。公开可访问或来自官方网站不等于获得这些用途的授权。
- S1/S2 只作人工结构参考；F1 只作团队内部人工风格讨论。当前没有任何一项可标记为“允许上传外部图生图服务”。

第一处端到端小样还需建模侧交付任意一个完整模板包，包括车型/模板版本、目标 mesh、材质槽、实际 UV、同尺寸遮罩、纹理规格、方向/接缝、棋盘格定位截图及恢复方式。该依赖属于 #37/#42，不以二维资料代替。
