## #32：建议要求补充一项产品边界后复审

### P2：前后对比必须继承预设来源标识与启用范围

位置：docs/prd/before-after-comparison.md:42–57（场景快照与页面标签）；验收用例103–112行。

文档允许将当前装配方案快照直接作为“改装后”，但整个PRD未规定通用预设的来源标识，也未引用本期仅启用排气/风挡、边箱隐藏的最新范围。#29提供的是无品牌示意资产，#5/#18负责人此前已报告在本地接入六件含边箱模型。即使场景输入完整，直接复制快照并只标“改装后”仍可能把通用预设表现为真实商品/真实装车效果，或让尚存于旧快照中的边箱重新进入产品演示。

请补充统一规则，而非另造公共接口：

1. 对比入口及两个显示模式继承场景中模型的来源/能力标记；只要使用通用预设，持续明确展示“预设效果示意”，不声称具体商品、车型适配或真实安装效果。
2. 不因进入对比而绕过产品启用范围。当前未启用边箱不进入用户对比/产品演示；不能为了隐藏而修改用户保存的原始方案，应按统一启用规则处理展示或拒绝该输入。
3. 缺少真实车型/具体商品模型证据时，不能由“文件能加载”推导适配成立；明确提示实际可提供的示意能力，不制造完整真实对比。
4. 增加“含预设的快照在分屏/单场景均保留提示”和“包含未启用边箱的旧快照不绕过范围”的验收用例。

该补充来自Ethan已确认的产品规则，不是新增车型或模型开发要求。
