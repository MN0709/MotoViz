## 结论

## 已知限制

1. 贴图文字指向 Ninja ZX-25R，但准确市场/年款仍需资料组核实；来源页的 2023-03-15 是素材发布日期，不能当车辆年款。
2. 模型长度约 1.1 Blender unit，尚未按可信整车尺寸换算成米。
3. 风挡测试使用本地测试 GLB；排气尚未完成替换验证。
4. 五处贴膜区域尚未导出正式 UV/遮罩包；现有贴图功能使用浏览器平面投射。
5. 前后轮仍把轮胎、轮毂和制动盘作为粗粒度组合，不适合商品级替换。
6. 素材已购买，但 [3D溜溜平台服务协议](https://service.3d66.com/rule/6.html) 与[商用实施许可授权合同](https://service.3d66.com/rule/48.html)禁止直接向第三方传播下载素材；未取得该素材的书面公开分发许可，因此模型和内嵌模型 HTML 不能作为公开交付链接。
