# 前端页面与联调记录

沿用 Ethan 的 #17 首页导航、#19 检索对话页，以及 Freya-Qian 的 #5/#18 场景与展示页职责，不新建团队、不重写官网。

## 两个业务入口

- 配件展示：车型 → 可替换部位 → 具体配件与来源 → 查看该产品支持状态 → 替换/恢复 → 旋转查看 → 保存/导出。
- 贴膜拉花：同一车型 → 目标区域 → 文字或参考图 → 生成/整理纹理 → 应用 → 旋转查看 → 保存/导出。

首页只需承接后续确认的两条入口；本轮不修改现有页面。用户不必手工输入内部 ID，但场景状态必须能追溯对应 ID 和版本。

## 页面状态要求

| 场景 | 应表现 | 禁止混淆 |
| --- | --- | --- |
| 已有参考近似模型且比例/替换验证通过 | 可选择替换、查看参考资料、恢复原车，标“改装效果示意” | 不要求一比一复刻；实际安装适配另记 |
| 有商品数据，无对应模型 | 显示资料与“暂不支持 3D”，禁用替换 | 不能自动展示相似预设冒充该商品 |
| 明确进入通用预设示意 | 持续标“预设效果示意”，仅4件启用资产 | 旧边箱不可通过其他入口露出 |
| 模型加载失败 | 保留/恢复可用原车状态，显示错误与重试 | 不让被隐藏的原车部件永久消失 |
| 贴膜生成/应用中 | 区分生成图与正在应用的纹理 | 不把二维输出当3D成功 |
| 贴膜生成或加载失败 | 保留上一有效方案或原车材质，可重试 | 不清空用户原有方案 |
| 导出效果图 | 与当前场景一致，保留必要来源/示意标识 | 不生成与实际选择无关画面 |
