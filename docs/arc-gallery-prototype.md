# MotoViz 开场原型（v37）

关联 Issue #17。本次保存已确认的开场视觉版本，主页仍待设计调整和业务接入；不关闭 Issue，不代表产品验收通过。

## 查看

在仓库根目录运行：

```sh
python3 -m http.server 4177 --bind 127.0.0.1 --directory apps/web/public
```

访问 `http://127.0.0.1:4177/prototypes/arc-gallery/`。也可以使用 `npm run dev` 后访问同一路径。该页面为独立静态原型，尚未替换 React 应用首页。

## 当前行为

- 十张真实摩托车照片组成连续三维飘带，统一带宽，按三维中心线实际弧长铺图，保留自然透视。
- 两排 MOTOVIZ / AI STUDIO 文字初始居中，随飘带开始运动逐渐分开，尾段与主页揭幕重叠；总时长约8.8秒。
- 开场只显示品牌和跳过。首页页脚提供手动重播与图片来源。
- 首次完成或主动跳过后保存本地访问标记，后续访问直接进入主页；手动重播仍可播放。
- 尊重减少动态偏好；图片加载超时或 WebGL 不可用时进入主页。后台标签页暂停动画。
- 字体与图片并行加载，等待预算1.8秒；这不等于首屏两秒性能验收。

## 图片与实现

`gallery.js` 管理播放、加载和 WebGL 渲染；`ribbon-math.js` 管理连续曲面与时序；`index.html`、`style.css` 提供开场与待调整的主页。

图片顺序按素材编号为03、01、04、06、08、10、07、09、02、05，穿插整车与细节、深浅画面；中段突出绿色BMW和蓝色Ducati。768×960杂志图片使用 `-v36.jpg` 文件，v37仅收起控件与技术文案。人工添加的细小署名移到来源页，原图水印保留。
