# MotoViz

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

面向摩托车改装店老板和店员。官网用于说明门店日常用途，并引导体验产品；本次不以项目评委或骑手消费者为主要受众。

## Product Purpose

通过 3D 改装效果展示辅助销售沟通，通过配件与故障检索辅助查询和诊断。仓库当前定位为小组实训 MVP，不宣称已完成商业上线。

## Operating Context

用户先访问独立官网展示页，再通过“进入应用”到达产品内首页。产品首页提供改装展示、故障诊断、配件查询三个入口和最近使用区域。

## Capabilities and Constraints

- 本任务处理 Issue #17 的首页与导航，并新增官网前置入口；保留原产品首页要求。
- Issue #19 检索对话页由另一任务推进，本任务仅处理入口与导航衔接。
- Issue #17 验收要求首屏加载不超过 2 秒、平板横屏布局正常；避免引入非必要 UI 依赖。
- 保留图片生成入口；生成失败切换预设模型并明确标注。这是已确认的产品决策，不代表当前前端已具备完整能力。
- 首批按 2–3 款车型规划，具体车型需模型资源与挂载验证后确定。
- 检索结果尚不支持 3D 时，仍展示配件信息，标注暂不支持 3D 并禁用挂载。
- 具体车型清单和联调时间未确定。
- 现有技术栈为 React、Vite、TypeScript，接口以仓库 docs/api-contract.md 为准。
